# Node Definition Name Guidance

## Purpose

Render name-writing guidance for node definition suggestions.

## Value

Name writing instruction: Put a short, clear Korean role name in patch.name. Do not use only a capability name or an alternative title. The name must show the sub-agent overview and selected role.

## Out Of Scope

- This module does not own topology persistence, execution routing, runtime delegation, memory writes, tool permission, channel delivery, logging, or final response wording.
