# Codex OAuth Fallback Prompt Labels

## Purpose

Provide prompt-owned English labels for flattened Codex OAuth fallback transcripts.

## Value

user_label=User
assistant_label=Assistant
tool_request_prefix=[tool request]
tool_result_prefix=[tool result]
default_prompt=Continue the conversation.

## Out Of Scope

- This module does not own OpenAI request formatting, retry policy, OAuth tokens, tool payloads, model selection, or message content.
