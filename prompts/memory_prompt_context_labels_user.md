# Memory Prompt Context Labels

## Purpose

Provide prompt-owned English labels for memory context blocks injected into agent prompts.

## Value

relevant_memory_header=[Relevant Memory]
flash_feedback_header=[Immediate User Feedback]
flash_feedback_note=This feedback is a short-lived execution correction, not a confirmed long-term rule.

## Out Of Scope

- This module does not own memory retrieval, memory chunk text, scores, dates, severities, storage, embeddings, or response rendering.
