# Node Definition Description Review Guidance

## Purpose

Render final review guidance for node definition descriptions.

## Value

Final review instruction:
After drafting patch.description, review whether responsibilities, input interpretation, decision criteria, work steps, handoff content, completion criteria, and risk or clarification items are missing.
Add missing details to the final patch.description only.
In rationale, briefly state what was strengthened after review.

## Out Of Scope

- This module does not own topology persistence, execution routing, runtime delegation, memory writes, tool permission, channel delivery, logging, or final response wording.
