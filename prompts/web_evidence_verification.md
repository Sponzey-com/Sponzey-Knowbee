# Web Evidence Verification

## Responsibility

Determine whether the bounded evidence pack supports a complete answer to the request.

## Rules

- Use only the supplied evidence pack.
- Mark the result `conflicted` when unresolved source conflicts affect a required fact.
- Mark the result `insufficient` when a required fact lacks support.
- Draft an answer only from supported units.
- Do not request tools, inspect raw documents, plan recovery, or deliver the user response.
