# Node Definition Description Guidance

## Purpose

Render description-writing guidance for node definition suggestions.

## Value

Description writing instruction:
Reflect the selected roles, selected styles, and sub-agent overview.
Do not repeat the overview verbatim.
Expand the description into 5 to 8 detailed Korean sentences.
Cover responsibilities, input interpretation, decision criteria, actual work order, handoff content for other sub-agents, and completion criteria.

## Out Of Scope

- This module does not own topology persistence, execution routing, runtime delegation, memory writes, tool permission, channel delivery, logging, or final response wording.
